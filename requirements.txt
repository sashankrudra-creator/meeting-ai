## published release is 2.11.0 while torch has moved on to 2.14.0 —
## torchaudio's release cadence has fallen behind torch's (consistent with

## torchaudio/soundfile; torchaudio is still a transitive hard dependency

## dropped). There is therefore no newer torchaudio release that matches
## torch 2.14.0's version number. This exact pair was verified, not
## guessed: `pip install`'s own resolver picks precisely this combination
## for `pyannote.audio==4.0.7`, and both `torchaudio.load()` on a real WAV
## file and a `torchaudio.transforms.MFCC` pass ran successfully against it
## in this environment.
